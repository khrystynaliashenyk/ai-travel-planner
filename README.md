# AI Travel Planner

## Запуск
1. Створи та активуй віртуальне середовище:
   `python3 -m venv .venv`
   `source .venv/bin/activate`
2. Встанови залежності:
   `pip install -r requirements.txt`
3. Запусти:
   `streamlit run app.py`
4. Введи Groq API key у бічній панелі.

Під час роботи агент створює `users.json` і `trips.json` поруч із Python-файлами.
`start_trip` реєструє користувача й початок планування; `update_trip` зберігає зміни;
`save_trip` зберігає погоджений маршрут, бюджет та історію чату.

Інструменти бюджету та маршруту працюють з орієнтовними даними. Проєкт не перевіряє
актуальні ціни, години роботи, наявність квитків чи готелів і не здійснює бронювання.
